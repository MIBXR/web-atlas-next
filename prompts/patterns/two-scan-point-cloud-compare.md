# 两次扫描的点云图层与比较 · 复用 Prompt

[结构化条目](../../entries/patterns/two-scan-point-cloud-compare.json)

为目标页面实现「两次扫描的点云图层与比较」：多视图复用同一点位数据，以分类权重显隐层，以scissor在分隔线两侧绘两个扫描状态，平面选择与截面共用z值和投影。触发：图层开关、分隔线或截面输入。结果：变化区、组成层和测量高度能在同一场地中核对。参数：场地=W=120，D=90，平台41.25，楼层3.6；扫带=hero 8s周期/6.4s穿越；layers 10s/7.2s；比较与截面=分隔4%–96%，键盘5%；切片半厚1.1，z量化.5。先读来源实际源码与 fidelity.md，以目标内容替换原作材料；开关与分隔线有语义名称、aria值和键盘输入。固定扫带与视角，图层、比较和截面按输入直接更新。
