# 把角色拖进产品演示 · 复用 Prompt

[结构化条目](../../entries/patterns/drag-mascot-into-product-demo.json)

实现「把角色拖进产品演示」：按下时记录指针与角色容器的握点偏移，移动时以可见身体锚点判定目标；命中后吸附到与工作姿态共用的位置，再触发产品界面。未命中则停在松手位置。触发：将角色的身体拖入虚线目标。参数：400ms cubic-bezier(.06,.06,.51,1.1)；Y偏移=角色尺寸×.266；可见身体约占宽度44%。先读取来源案例的实际源码与 fidelity.md，保持角色 SVG、身体锚点、状态交接和原声音行为。原作没有键盘拖放入口；迁移时提供原生按钮触发同一吸附与界面状态。原作保留吸附；迁移时可直接落到工作位置，再显示可读的产品界面。迁移时替换为有使用权的角色与素材。
