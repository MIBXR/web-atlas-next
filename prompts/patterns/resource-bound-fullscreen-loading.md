# 真实资源驱动的全屏载入 · 复用 Prompt

[结构化条目](../../entries/patterns/resource-bound-fullscreen-loading.json)

为【资源较重的入口】实现真实资源驱动的全屏载入。列出当前入口必需图片/字体，按完成任务显示进度，不按时间伪造百分比或等待全站影片/BGM；完成比例与成功条件分开。关键任务失败即使100%也显示可读错误和重试/继续，只有成功或用户明确继续才移交场景。可用静态品牌/短wipe承接退出，正文和目标章节可达；同一入口不叠第二套欢迎。明日方舟使用五图基线，终末地使用本地关键首页、干员图与字体任务集。键盘可操作失败路径，加载状态用文本可读；减少动态保留真实进度并即时移交终态。分别验证冷/暖载、失败/重试和入口退出时序，源码外观、本地任务集和实测范围明确区分。

## 制作约束

- 失败时提供重试/继续路径，只等待首屏必要资源；来源与本地图片集及保底等待须分开标注。
- 迁移时替换为有使用权的素材与真实内容，来源快照的数值需按目标任务重新验证。
- 终末地的公开 Updating 图形与黄色 wipe 沿用源 CSS；本地关键首页、干员图与字体任务集，以及按任务完成比例显示的进度和重试/继续路径为本地适配。
- 区分任务完成与成功：关键图失败时，即使显示100%也保持error/ready pending，直到重试成功或用户明确继续；目前已实测失败重试，“继续”未单独验收。
