# 用配置文本字符成像 · 复用 Prompt

[结构化条目](../../entries/patterns/dotfile-glyph-portrait.json)

为目标页面实现「用配置文本字符成像」：从灰度格提取亮格，以配置字符循环填格，亮度决定字号、字重和颜色；逐行由扰动字符解析，指针热度短暂替换字符后冷却。触发：图像入场或指针经过。结果：图像既有主体轮廓，也能近看出产品材料。参数：图像数据=hare 132×110，mark 250×31，纵横比1.85；入场=逐行1100ms加0–420ms抖动，单格扰动260ms；指针=半径7格，heat每帧乘.9。先读来源实际源码与 fidelity.md，以目标内容替换原作材料；图像之外保留可读品牌与实际安装命令。直接绘制最终字符与色阶，停用解析和热度。
