# 指针拨开、选择染色的香气场 · 复用 Prompt

[结构化条目](../../entries/patterns/gesture-cleared-scent-field.json)

为目标页面实现「指针拨开、选择染色的香气场」：域扭曲噪声绘上升雾，试香纸几何给羽流源；环形指针尾迹减弱附近密度，香型目标色缓慢混入环境和羽流。触发：移动指针或选择香型。结果：香气成为可操作、可辨认且与试香纸相连的材料。参数：渲染=CSS尺寸×.5；初始时间37；尾迹=8点、70ms落点、150px半径、.75s衰减；色调=目标色时间常数.9s，环境混合比.55。先读来源实际源码与 fidelity.md，以目标内容替换原作材料；香型由可聚焦按钮选择，背景画布不截获主体操作。保留静帧和即时换色，停用连续噪声与尾迹。
