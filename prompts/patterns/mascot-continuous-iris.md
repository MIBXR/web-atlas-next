# 角色跨圆幕保持视觉连续 · 复用 Prompt

[结构化条目](../../entries/patterns/mascot-continuous-iris.json)

实现「角色跨圆幕保持视觉连续」：把主角放在圆形背景遮罩之上；标题倒删后先将主角移到揭幕中心，再扩张背景并缩小角色，退出时反向收幕而角色持续可见。触发：标题结束或二次拒绝后收场。参数：circle(0) → circle(150vmax)，圆心50vw 50vh，800ms ease-out；1500ms cubic-bezier(.4,0,.2,1)。先读取来源案例的实际源码与 fidelity.md，保持角色 SVG、身体锚点、状态交接和原声音行为。原作 Escape 可跳至等待态；移植时保持可直接进入内容的按钮。原作未停用圆幕；移植时可即时换底色并保留角色位置。迁移时替换为有使用权的角色与素材。
