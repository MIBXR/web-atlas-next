# 权限选择驱动角色与页面分支 · 复用 Prompt

[结构化条目](../../entries/patterns/expressive-permission-branches.json)

实现「权限选择驱动角色与页面分支」：把允许、首次拒绝与再次拒绝保存为有限分支；一次选择同时更新权限卡、终端结果、角色动作与后续页面。过渡期间锁定重复输入，第二次拒绝结束请求。触发：点击 Allow 或 Deny。参数：卡片400ms淡出，舞台500ms退出后显示六格画廊；180ms退卡→1000ms趴地→1500ms起身→700ms挠头→撒娇重试；再次拒绝800ms居中并进入4400ms墨镜告别。先读取来源案例的实际源码与 fidelity.md，保持角色 SVG、身体锚点、状态交接和原声音行为。Allow、Deny、重播和产品链接均为原生控件；原作到达权限阶段前仍需拖放。原作保留分支表演；迁移时即时显示选择结果，保留重试与结束路径。迁移时替换为有使用权的角色与素材。

## 制作约束

- 只从角色或界面本身取材，不用整个页面的截图替代机制。
- 角色与官网素材保留原权利；迁移时使用有对应授权的资源。
