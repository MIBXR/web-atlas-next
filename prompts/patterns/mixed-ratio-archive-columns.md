# 等宽栏目保留不同图像比例 · 复用 Prompt

[结构化条目](../../entries/patterns/mixed-ratio-archive-columns.json)

为【目标页面/组件】实现「等宽栏目保留不同图像比例」。栏目有共同宽度与标题规则，内部竖海报、横摄影按各自比例排列；不同内容长度产生不同列高，手机逐列阅读。可见结果：分类稳定而作品保持完整。适用任务：多类型文化资料库。阅读顺序按DOM栏目组织，手机避免视觉顺序与语义顺序不同。键盘：保留语义标题、顺序阅读与图像替代文字；装饰不进入Tab顺序。减少动态：布局与内容保持可读；不为静态构成增加自动运动。

## 制作约束

- 按 DOM 栏目组织阅读顺序，手机上的视觉顺序与语义顺序保持一致。
- 迁移时替换为有使用权的素材与真实内容，来源快照的数值需按目标任务重新验证。
