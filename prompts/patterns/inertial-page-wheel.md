# 惯性三维页面转轮 · 复用 Prompt

[结构化条目](../../entries/patterns/inertial-page-wheel.json)

为目标页面实现「惯性三维页面转轮」：按卡数计算圆柱半径和步角，指针位移换算角度与速度，松手后摩擦衰减再吸附；新拖动取消目标和惯性，首次接触永久停止闲置自转。触发：拖动、松手、方向键或闲置等待。结果：页面具有连续空间位置，主动浏览接管闲置演示。参数：卡数与步角=17张；360/n≈21.176°；动力=目标趋近.14；速度乘.93；速度阈值.02°/帧；闲置与拖动=闲置-.06°/帧；拖动超过6px阻止打开。先读来源实际源码与 fidelity.md，以目标内容替换原作材料；区域支持方向键和显式前后按钮，保留列表入口。停用闲置自转，以即时选择替代惯性与吸附运动。
