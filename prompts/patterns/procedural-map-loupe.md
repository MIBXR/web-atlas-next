# 重绘程序地图的放大镜 · 复用 Prompt

[结构化条目](../../entries/patterns/procedural-map-loupe.json)

为目标页面实现「重绘程序地图的放大镜」：固定噪声经marching squares生成等高线与地块，放大镜裁切局部并按倍率重绘路线和地物；指针移开后回停到门边。触发：鼠标进入地图、移动或离开。结果：细察保持地图清晰，也与农场日志有共同空间基准。参数：等高线=5px采样格；两轮Chaikin；每第五条加粗；放大镜=半径76px；倍率1.9；画布边长200px；跟随=60/110ms时间常数，回停260ms。先读来源实际源码与 fidelity.md，以目标内容替换原作材料；日志保留可聚焦图钉与卡片，放大镜为细察辅助。保留固定地图和停靠放大镜，选择即时完成。
