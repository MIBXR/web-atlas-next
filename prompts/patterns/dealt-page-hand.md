# 发牌式真实页面手牌 · 复用 Prompt

[结构化条目](../../entries/patterns/dealt-page-hand.json)

为目标页面实现「发牌式真实页面手牌」：桌面牌与手机牌沿浅弧交错布置，聚焦或悬停抬牌并让邻牌退让；重抽排除当前主题，等图像 decode 与收牌完成再替换，busy 防止连按再入。触发：首入、悬停或聚焦卡片、激活 Deal again。结果：页面证据可浏览，换牌过程连续且新牌有完整图像。参数：几何=间隔 max(14px,.07W)；弧高 .055W·u²；旋转2.9u°；抬升与入场=抬高.1W；相邻让位.06W/.035W；交错55ms；换牌=等decode与560ms收牌；重发后1000ms解除busy。先读来源实际源码与 fidelity.md，以目标内容替换原作材料；卡片和重抽均可聚焦，卡片保留实际链接。直接布局与换图，保留重抽、名称和打开动作。
