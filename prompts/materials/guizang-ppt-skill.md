# 歸藏 PPT Skill · 杂志风与瑞士风网页演示 · 复用 Prompt

[结构化条目](../../entries/materials/guizang-ppt-skill.json)

阅读 guizang-ppt-skill 原文，按七问确定受众、时长、内容、图片、主题与约束。选择一套风格，复制对应模板，先规划明暗节奏，再从对应版式库填入页面。每页保留稳定 data-slide-id，按 presenter-mode.md 生成目的、讲述要点、转场和用户提供的计划时长。配图按宿主能力与用户要求生成，比例与槽位对应。按 checklist.md 和两个校验器检查，在浏览器逐页预览并排练演讲者与观众屏同步。

## 制作约束

- 配图流程依赖 GPT-Image 2.0 / GPT-M 2.0 的宿主能力。
- 两套风格使用各自的模板、主题与版式类；同一份演示文稿采用一套风格。
