# Anime.js · JavaScript 动画引擎 · 复用 Prompt

[结构化条目](../../entries/materials/animejs.json)

读取 animejs 素材的中文说明与相关上游样例，以 Anime.js 4.5.0 实现目标网页动效。按元素与属性选择 animate，用 stagger 组织分布，用 createTimeline 协调先后，用 onScroll 连接滚动，用 createDraggable 处理拖拽，用 svg 工具处理描线与路径。保持独立变换、作用域和销毁关系与所取样例一致。

## 制作约束

- Anime.js 固定 v4.5.0 与完整提交，样例保留原始目录层级。
- 36 个样例共用完整 dist/，Three.js 固定 0.184.0，tweaks 固定 0.3.4。
- 远程字体、随机图片和两处源码适配见样例索引。
