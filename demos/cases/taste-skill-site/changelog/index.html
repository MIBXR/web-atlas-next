What changed, release by release.

Release notes for design-taste-frontend, newest first. The current version is 2.1.5.

CHANGELOG.mdReleases on GitHub

2.1.5

25 October 2026Latest

Fixes from the community: safe chart text, kept screenshots, keyboard access and real italics.

  • charts.js and the split-heading fallback escape the text they insert, so a label from user data cannot inject markup (#160, #169).
  • Two widths of the same class no longer overwrite each other's screenshots: --widths 1280,1024,768,390 keeps both tablet renders (#162, #165).
  • Every control works from the keyboard and has an accessible name, and explains itself by its form rather than a sentence beside it (#170).
  • Boska, Erode and Sentient load their real italic weight instead of a faked one (#161, #166).
  • edge-text no longer fails lines cut off with an ellipsis (#156).
  • The gate runs its last check on the production build, and the inspector warns (dev-server) when it looks at a Vite, webpack or Next dev server (#171).
  • The redraw rule names its third reason: a section that cannot hold the real content (#163).
  • CI also checks that every text file is clean UTF-8, runs the inspector file-name tests and parses the scene scripts.

Release on GitHub

2.1.4

20 October 2026

One inspector run can no longer delete the browser profile of another.

  • On macOS and Linux a second run could remove the Chrome profile of a long run still going. Fixed by @t4sh with a regression test (#157, #158).
  • Leftover profiles are cleaned up again, safely: each carries taste-skill-owner.json, and a later run removes only a profile left by a dead run on the same machine.
  • Profiles from earlier versions are not removed. Delete the ad-chrome-* folders in your temp folder, or in TASTE_SKILL_TMP, by hand.

Release on GitHub

2.1.3

19 October 2026

One repo, one skill. Nothing in design-taste-frontend changed.

  • The classic skills moved to taste-skill-classics with the same install names, and their Claude Code plugin moved with them.
  • The pointer folders for the image skills and for redesign-existing-projects are gone. The README lists where every old install name lives now.
  • Removed: research/laziness/, the outdated skills/llms.txt, skill.sh and unused images.
  • The Codex plugin loads only design-taste-frontend.

Release on GitHub

2.1.2

19 October 2026

Fix: the skill did not load in Claude Code.

  • The description added in 2.1.0 held an unquoted colon, so the frontmatter failed to parse and Claude Code dropped the skill with "Unknown skill" (#151). It is now a folded block.
  • tests/frontmatter.mjs parses every frontmatter with a strict YAML parser, and a GitHub Actions workflow runs it, the registry test and a syntax check of the scripts on every push and pull request.

Release on GitHub

2.1.1

19 October 2026

One skill to reach for.

  • The classic skills are opt-in: they run only when called by name, in Claude Code, in Codex and in every other agent.
  • Redesigns are part of the main skill: record the before in a real browser, keep the stack and the content, change type, colour, the frame, states and stock components in that order, and prove it with before and after. redesign-existing-projects is retired.
  • The image-generation skills moved to imagegen-skills, with the same install names.
  • full-output-enforcement is removed.
  • Two Claude Code plugins: taste-skill with the default skill, taste-skill-classics with the classic ones.

Release on GitHub

2.1.0

19 October 2026

App screens, the frame of a page, the scroll-scene engine and a study of 100 Sites of the Day.

  • App screens. Dashboards, admin, settings and inboxes get their own route: references/app-screens.md, draw.mjs --app with seven styles, inspect.mjs --app and lint.mjs --app, assets/app.css and assets/charts.js. Distilled from 23 real product screens and tested in four blind rounds.
  • Product pages that show their app build every interface fragment as a real piece of the app, with real data that adds up.
  • The frame. The inspector measures no-title, off-centre, lopsided, empty-middle, blank-gap, untitled-section, edge-text, ragged-edges and more, with thresholds taken from the study.
  • The scroll-scene engine: a sticky stage in assets/scenes/, scenes.mjs to photograph each scene through its hold, and inspect.mjs --film. The library of scenes follows in 2.2.
  • A study of the latest 100 Awwwards Sites of the Day, captured on 18 October 2026: new guidance on where pictures go and how strong pages move, 10 hero and 13 section compositions, and 21 new studied sites.
  • New checks: late-title, reduced-hidden and no-poster. The inspector's throwaway Chrome profiles are removed reliably, and TASTE_SKILL_TMP moves them off the system drive.

Release on GitHub

2.0.0

13 October 2026

A new skill, built from a study of 247 curated sites.

  • design-taste-frontend is now v2, under the same install name: a folder with instructions, reference files, a library and four zero-dependency scripts.
  • A build runs in six steps: inventory, draw, the idea and one live thing, build, gate in a real browser, and look and fix.
  • assets.mjs finds real pictures and footage in open collections without API keys, downloads them and records their credits.
  • The inspector requires pictures and motion: few-pictures fails a page with fewer than four real pictures, still-page one where too little moves.
  • Tested in five rounds of blind comparisons on six briefs. In the final round the v2 pages measured 0 inspector failures each, the pages built without a skill 8 to 13.
  • The previous default and v1 stay installable under their own names. Codex can install the skill as a plugin.

Before v2

February to May 2026

The skill began as a single SKILL.md, then grew into a collection of style and image skills. The milestones before 2.0.0:

v2 (experimental)May 2026
A rewrite of the original skill with brief inference, hard bans and three dials. It was the default until 2.0.0 and installs today as design-taste-frontend-v2-experimental from taste-skill-classics.
v1.2May 2026
Composition, background and one-image-per-section rules for imagegen-frontend-web.
v1.1April 2026
gpt-taste, image-to-code and the image-only skills for web, mobile and brand kits, the MIT licence, and --skill for installing a single skill.
v1.0March 2026
The npx skills layout, with the soft, minimalist, brutalist, Stitch, output and redesign skills next to the main one.
v0.1February 2026
Taste Skill ships as a single SKILL.md with three dials and anti-slop rules.

CHANGELOG.md covers v1 and every release since 2.0.0; the earlier milestones are in the commit history.
