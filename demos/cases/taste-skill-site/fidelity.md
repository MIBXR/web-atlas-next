# Taste Skill 官网复刻对照

采集日期：2026-11-19。原站地址：https://www.tasteskill.dev/ （由 https://tasteskill.dev 解析，线上部署标识 `dpl_p6tE71r3jRSWDdmahXrJaf8t29eg`），对应上游技能仓库 `Leonxlnx/taste-skill@f6b76575f949707b4e3c37cd86cb44b0b98643e8`（`v2.5.1`，官网文档标注 `v2.1.5` 里程碑说明）。

复刻范围覆盖官网首页（`index.html`）全部 12 个模块与导航栏 4 个子页（`docs/index.html`、`guide/index.html`、`changelog/index.html`、`blog/index.html`）。

## 源码与本地化处理

1. **原始分块与运行实现**：原站为 Next.js App Router + Tailwind CSS v4 生产构建产物，原始 HTML、CSS 与 JS 分块保存在 `source/upstream/`，模块对应关系记录于 `source/trace.json`。运行页面移除了 Next.js RSC 飞行载荷、预取请求及第一方统计脚本（`/b4fd3029e43aee70/script.js`），直接复用原站解包的 `GSAP 3.15.0`（`gsap.js`、`ScrollTrigger.js`、`SplitText.js`）、`Lenis 1.3.26`（`lenis.js`）、场景调度器 `js/stage.js`、三个核心场景模块（`js/scroll-turned-drum.js`、`js/before-after.js`、`js/light-flood.js`）以及可读交互脚本 `js/app.js`。
2. **字体与媒体本地化**：原站 `17z1goe0jn.3s.css` 定义的 21 个 `Google Sans Flex` 与 `Google Sans Code` WOFF2 字体分片全部保存在 `fonts/`，由 `fonts.css` 本地加载；原站通过 `/_next/image` 加载的 9 张作品与缩略图（`assets/work/*.webp`）、品牌与赞助商图标（`assets/sponsors/*`）、6 个 Agent 图标（`assets/icons/*.svg`）和 23 张 GitHub 社区赞助者头像（`assets/avatars/*.png`）全部本地化并由 `AtlasAssets` 统一解析。
3. **无声设计**：原站全站无音频或视频元素（`0` `<audio>`、`0` `<video>`），本地保持无声。
4. **Blog 子页外部嵌入**：原站 `/blog` 动态请求 `platform.twitter.com/widgets.js` 渲染 4 条 X 推文，受隐私或网络拦截时显示原站内置的 4 张 `.surface.post` 引用卡片与 `"View post on X (1–4 of 4)"` 链接；本地遵循不加载第三方追踪脚本的原则，直接呈现原站内置的 4 张推文卡片与外链入口。
