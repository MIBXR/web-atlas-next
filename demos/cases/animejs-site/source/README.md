# Anime.js 官网首页来源

原站：https://animejs.com/ 。取证日期：2026-11-02。发布入口为 `assets/js/home.js?v=1787698626`，样式为同查询串的 `core.css` 与 `home.css`。

运行库为 Anime.js 4.5.0、Three.js r172、postprocessing 6.36.6 和 highlight.js 11.11.1。Anime.js 上游提交为 `2c9cf8ea00329f6768c7d7902252ed977d75ce42`。归档的首页 JS 和分块均无 sourceMappingURL。
