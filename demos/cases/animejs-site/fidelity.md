# Anime.js 官网首页对照

来源：https://animejs.com/ 。归档日期：2026-11-02。固定库版本和源码定位见 [source/README.md](source/README.md)。

## 范围

原始 HTML、两份 CSS、字体、SVG、模型、赞助标志与名单构成首页。站点代码按导航、仪表盘、八节 API 演示、模块场景、赞助与页脚分文件实现；数值定位见 [source/values.md](source/values.md)。赞助名单、资金数据与头像采用归档日快照。

## 已接受差异

运行页移除 gtag 和 Carbon 脚本。页脚广告位为空，保留[原站容器尺寸](source/values.md#carbon-容器布局)。

## 对照条件

Edge，DPR 1，1440×900 与 390×844。两个视口分别覆盖浅色与深色、正常与减少动态。

## 对照结果

8 组组合均加载全部 22 个 GLB。原站和本库各有 6 个 Canvas，480 组对齐的 Canvas 帧逐像素一致。两个视口各 68 条文案与链接一致。原站自身重复绘制时，页面边缘也有光栅波动。

8195 条覆盖记录中，8194 条一致，1 条为页脚广告差异。模块最长 64 秒循环的动画时刻、位置、旋转与缩放一致。

独立页面与站内预览使用 Web Atlas 共用的细滚动条。
