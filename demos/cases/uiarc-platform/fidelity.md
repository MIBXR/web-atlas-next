# Arc UI 官网首页 · 复刻对照

## 范围与条件

原站为 [uiarc.dev](https://uiarc.dev/)，采集日期为 2026-11-01，范围是英文首页：导航、首屏、客户标识、两组产品媒体、安装入口、价格、FAQ、最终行动及页脚。目录、文档、Showcase、Pro、账号与交易使用原站入口。

原站与本地使用同一 Chromium 浏览器，在 1440×1000 和 390×844 CSS 视口、DPR 1、相同主题下对照。顶部推广条按任务要求移除；同条件对照时先关闭原站公告，手机菜单从 y=68px 开始。预览使用稳定的浅色画面，在主题过渡和文字入场结束后截取内容区域，不含滚动条；页面没有加载整站截图。原始字体、标识、海报与静音影片保留，几何与时序同时参照公开 DOM、计算样式和发布代码。

本地使用 `app.js` 实现主题、标题、标识和媒体管理，`source/components.tsx` 组合固定免费源码中的组件。发布代码保存在 `source/site-scripts/` 供参数溯源，本地不执行这些发布包。

## 实现边界

- 免费组件的原始 TypeScript 和 CSS Modules 由 Arc UI 素材共享，构建依赖与许可随本体保存；官网其余结构按公开页面与发布参数实现。
- 金额、内容数量和 GitHub 星数固定为采集快照；账户、交易弹层、实时计费请求与统计不接入本地，价格动作通往官方价格页。
- 实测范围是 Chromium 桌面窗口及手机宽度模拟。真实触屏、其他浏览器、慢网络失败恢复及真实后台切换没有作为本次通过结论。
