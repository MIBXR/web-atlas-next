使用同一台 Windows 上的 Edge，以 1440×900 和 390×844 CSS 视口、DPR 1、页面缩放 100% 对照。先观察公开原站，再操作本地独立 Demo；截图保持完整视口，没有用截图覆盖实现，也没有修改原作绘制代码来制造一致画面。

## 交互与状态矩阵

| 模块／状态 | 原站定位 | 触发与原站可见响应 | 本地对应与判定 |
| --- | --- | --- | --- |
| 开场 | body[data-frame]、#brand-text | 光标停留→标题逐字输入→闪烁→倒删→角色移中→圆幕揭开→等待拖放；重复访问仍播放，Escape 跳到等待态 | 同一 scene.js、typewriter.js 与 CSS，已观察首入及重播。 |
| 注视 | #eyes-js、#body-js、#shadow-js | 指针到 (950,360) 时，眼睛 translate(2.5,-1)，身体 translate(1,-0.5)，影子 translate(0.5,0) scale(1.15,1) | 同视口实测值一致；场景表演时回正或交给光标。 |
| 眩晕 | #clawd.is-dizzy | 同向围绕角色两圈后眩晕；拖放按下立即取消 | 两端均用实际指针事件触发 is-dizzy，随后拖放能接管。 |
| 像素花园 | .flower-field | 同一指针坐标激活19朵邻近花；移开淡去；触摸结束清除 | 同点激活数一致，装饰层不挡输入。 |

| 命中与终端 | #clawd-body-point、.terminal-up | 身体进入目标后400ms吸附，终端升起并逐字播放请求、思考和权限 | 桌面鼠标与窄屏触摸仿真均完成；身体落点、终端状态和文字一致。 |
| 角色穿过终端 | .clawd-untyping 至 .clawd-alerting | 敲字→横行→被终端遮住→右侧探头→跳到请求旁 | 沿用原始 CSS、SVG 和 terminal.js 的140/1660/1200/1650/350ms参数；顺序保留。 |
| 初次允许 | .perm-card-allow | 收起权限卡和终端，出现六格动作 | 原站实测；与重试允许共用 playAllowSequence。 |
| 拒绝后允许 | .perm-card-deny、.clawd-perm-retry | 第一次拒绝给角色反应和一次重试；重试可允许 | 两端均走通；本地连续允许点击只进入一次画廊。 |
| 两次拒绝 | .clawd-exit-shades、#exit-credit | 回中→戴墨镜→米色圆幕收回→道谢 | 两端均走通并截取告别状态。 |
| 七次点击 | #clawd、#exit-toast | 告别锁定后点角色七次，出现作者文案并在5秒后消失 | 两端均实际触发，保留原作正文表情符号。 |
| 画廊 | #showcase | 六格动作，窄屏两列；内容独立滚动，GitHub指向真实产品仓库 | 两端全部到达，SVG完整加载，底部入口可见。 |
| 重播与键盘 | #showcase-replay、Allow/Deny | 原生按钮支持 Enter，重播重新进入开场；Escape只跳过开场 | 两端实际操作；拖放本身没有键盘替代。 |
| 后台恢复 | visibility-guard.js | 失焦超过1000ms，非稳定表演段返回前台会重载；画廊、退出锁定和权限空闲态保持 | 原始脚本保留，切换观察时已遇到重播／恢复；没有改成另一套暂停策略。 |
| 声音与主题 | 页面与全部脚本 | 无音视频、Web Audio、声音按钮或用户主题选择；黑／米色按场景交接 | 本地保持无声及固定场景色，不新增音乐或主题控件。 |
| 减少动态 | responsive.css、内联样式 | 花朵过渡关闭、拖放提示不摇动、引导手隐藏；开场和角色表演仍存在 | 保留来源范围；不宣称整个演出静止。 |

## 接入差异与限制

- 运行入口本地化字体及相对路径，直接加载 `source/website/` 的原始脚本和响应式 CSS。原始部署 HTML 也保留在该目录；没有重构角色动画与场景状态机。
- 去掉运行入口的 Cloudflare 统计、开发调参脚本和调试快捷入口；原始源文件仍留在 `source/website/`。
- 重播与仓库入口的两个文字功能图标换为带 viewBox 的 SVG，按钮文案、尺寸职责与去向保留。
- Google Fonts 的服务响应会随客户端返回不同格式；本地保存此次取得的完整 TTF 原件及 OFL，页面字体家族、字重和换行已对照。
- 案例内部的原文、终端小字、作者水印与题注保持原作尺度；参考库外层说明使用中文，主站界面没有修改。
- 原作没有键盘拖放替代，也没有完整静态的减少动态流程；本案例没有将这些改为本地新交互。慢网、资源失败恢复和真实移动设备未做仿真验收；窄屏与触摸结果来自 Edge 设备仿真。

制作文件与许可分别见 [source/README.md](source/README.md) 和 [LICENSES.md](LICENSES.md)。
