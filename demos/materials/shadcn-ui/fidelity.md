# 样例对照

组件样例使用固定提交中的 Base UI 源码，预览统一套用 Vega。站内页眉显示样例名称和文档入口，区块保留自己的页面布局。头像和示例图片使用本地占位图，原始引用保留在上游源码里。

| 样例 | 观察与本地结果 |
| --- | --- |
| [Accordion](https://ui.shadcn.com/docs/components/base/accordion) | 配送说明默认展开。打开退货说明后显示对应段落。 |
| [Data Table](https://ui.shadcn.com/docs/components/base/data-table) | 输入不存在的邮箱后，数据表显示空结果。 |
| [Sidebar 07](https://ui.shadcn.com/blocks/sidebar) | 手机视口的侧栏按钮打开抽屉。 |
| [Login 03](https://ui.shadcn.com/blocks/login) | 登录表单保留输入和浏览器校验，提交留在演示页。 |

样例在 Edge 的 1440 px 和 390 px 视口加载。轮播在窄屏预留两侧箭头空间。

深浅色切换沿用 Web Atlas 的主题入口，样例使用组件库自身的主题色值。
