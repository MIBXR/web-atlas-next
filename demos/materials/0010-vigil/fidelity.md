# Vigil 复刻对照

24 件均已实现为可运行的 WebGL2 画面，判定均为“近似”。弹窗按原件像素绘制；漩涡呈贯穿全幅的连续S形卷绕，冰面阶地的帘片轮廓与靛蓝阶地的层间点彩仍有差异。

## 对照条件

原作来自 [来源表](source/README.md) 的 15 条帖子。弹窗视口为1440×900，DPR 1。复刻缓冲区固定为原件宽高，CSS缩小显示；原作按相同画幅完整显示。视频对照 `t=0`、`t=5`，静帧对照 `t=0`；浏览器为无头 Edge，独立配置目录，浅色偏好。

尺寸误差换算到 1080 宽。大形数据为抑制点纹后的边界最近距离，记为“90分位 / 最大值”；球体数据为局部圆边缘拟合的圆心偏移与半径差的最大值。颜色为排除球体后八个场值分区均色的最大 CIE76 ΔE。点密度为排除框、球与细线区后，各分区局部对比点连通域数量的最大相对偏差；原件点数少于30的分区不参与百分比计算。家族按横向分区计算。帧间能量为相邻 1/30 秒 RGB 平均绝对差，在0秒与5秒两处取较大相对偏差。

判定以弹窗中是否呈现同一张画的两个版本为准。辅助指标为大形位置≤8px、球体与日食位置及半径≤4px、ΔE≤5（夜色漩涡≤8）、分区点密度±15%、帧间能量±25%；点彩按分布与密度对照。数值取自弹窗中的原尺寸复刻缓冲区与同一时刻的视频解码帧。

## 重点构成

| 项目 | 结果与差异 |
| --- | --- |
| 弹窗分辨率与细线 | 24件复刻缓冲区与各自原件宽高一致，CSS控制显示尺寸。同心细线及缩放干涉纹可见；其他线带按原尺寸绘制后缩小。 |
| 夜色漩涡 | 连续位移形成贯穿全幅的S形卷绕，扭转角随半径平滑衰减；黑洞RGB为0、0、0。灰蓝点带宽度、右侧粗点层次和内圈间距有差异。 |
| 冰面阶地 | 线带按1080×1920绘制；转角仍偏折线，片内从密点到细线、亮面的渐变与原作不同，帘片结构仍有差异。 |
| 靛蓝阶地 | 重复阶梯沿对角方向展开，层内点密度、颜色与细线连续变化；部分层间过渡合并，亮点带偏稀，局部点径偏大。 |
| 家族周期 | 四件家族12.8秒，六件家族14.4秒；messenger沿完整路径移动。 |

## 运动

框、带场大形与主要球体固定，颗粒沿带场切向移动。单件周期10秒，四件家族周期12.8秒，六件家族周期14.4秒；静帧固定为t=0。

家族messenger在相邻采样间插值，横向跨画纸边界时保持行进方向。子件的颗粒运动与家族使用同一周期。

## 音轨

有音轨的9件：`steps-blush`、`rings-green-eclipse`、`scallops-teal`、`terrace-ice`、`rings-olive-void`、`steps-rose`、`swirl-night`、`steps-rust-teal`、`dunes-navy-sun`。其余原件没有音轨。
