# Arc UI 免费预览与代码 · 对照结果

## 范围与条件

参考 [官网组件目录](https://uiarc.dev/components/button)，免费范围以素材条目固定的 registry 为准：120 个组件、22 个区块。每项提供实际预览与代码；不收录 Pro 实现，也不复制官网的 When to use、Usage 和 API 文档页面。

组件与 CSS 原文保存在 `source/upstream/`，预览组合在 `source/previews/`。区块优先运行上游自带样例，其他预览使用对应原始组件与本地演示数据。外框沿用官网的目录层级、图标标签和代码排版；中文名称为本库译名，英文名称与 API 标识保留。

使用同一 Chromium，在 1440×1000 与 390×844 CSS 视口、DPR 1 下核对。预览图使用浅色；主题过渡与首屏入场完成后，截取页面内容区域，排除滚动条。
