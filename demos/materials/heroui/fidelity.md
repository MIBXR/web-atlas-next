# 样例对照

样例来自 HeroUI 3.2.7 的 React Web 文档，以同版本组件和样式运行。样例容器限制在视口内，头像使用本地占位图。

| 样例 | 观察与本地结果 |
| --- | --- |
| [Modal](https://heroui.com/en/docs/react/components/modal) | 打开后显示对话框。按 Escape 关闭，焦点回到触发按钮。 |
| [ComboBox](https://heroui.com/en/docs/react/components/combo-box) | 输入 cat 后选择 Cat，输入框显示当前选中项。 |

73 个样例在 Edge 的 1440 px 和 390 px 视口加载。

深浅色切换沿用 Web Atlas 的主题入口，样例使用组件库自身的主题色值。
