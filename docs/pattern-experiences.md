# 巧思的体验类型与来源定位

巧思以可独立借用的机制为边界。完整案例保留布局、素材与交互的协作关系，巧思库帮助判断哪一部分适合当前任务；没有独立机制的案例无需提取，也无需凑齐视觉、动效和声音。

## 两个检索维度

[字段定义](../CONTRIBUTING.md#巧思)规定体验类型与用途分类。`experienceTypes` 回答“用户怎样感知或操作这个机制”，`category` 回答“机制承担什么用途”。例如，单开内容既有局部展开反馈，也有控制信息密度的职责，可同时标为“微动效”和“信息与状态”；用途仍是内容组织。已有用途类别保留，不用一种分类替代另一种。

| 体验类型 | 适配时关注 |
| --- | --- |
| 视觉构成 | 重点、比例、对齐与阅读层级。 |
| 微动效 | 触发、回程、焦点与触控。 |
| 主体与页面动效 | 内容交接、方向、时序、反向与快速输入。 |
| 声音与音效 | 主动启用、静音、重复、后台和声音归属。 |
| 信息与状态 | 当前范围、位置、选择与返回路径。 |

按每项实际机制判断类型。画面尺寸不是微动效与页面动效的唯一分界：背景光点可以辅助阅读，主要媒体窗口的交接可以承担主体叙事。响应点击也不自动成为动效；即时更新条件、收藏或正文仍可以是信息与状态。同一机制确有不同职责时，可标注多个类型，不从案例整体风格或声音标签自动补齐。

## 详情中的来源定位

详情自动载入当前来源，并进入这个巧思的观察区域。短暂框选标识在四秒后消失，工具栏“重新定位”可返回该区域，当前展开项和选择会保留；“重播”重新载入完整 Demo。切换来源后，观察位置与操作指引随之变化。定位逻辑位于 `site/src/stage.tsx`，来源选择与详情展示位于 `site/src/details.tsx`。

封面来自该巧思对应的真实区域与交互状态。同一案例中的标题、菜单、摄影或局部控件分别取景，完整来源 Demo 保留原有浏览与交互。声音通过来源自己的控件启用。

## 共享本地示意的取材依据

设计实验室“巧思机制实验”章节集中展示五种机制，逻辑位于 [site/core/lab/playground/](../site/core/lab/playground/)，界面位于 [site/ui/lab/](../site/ui/lab/)。示意用少量内容解释设计作用，完整来源、参数与证据由巧思包和来源案例提供。

| 示意 | 取材巧思 | 保留的机制与适配边界 |
| --- | --- | --- |
| 视觉强调 | [单一信号色集中强调](../entries/patterns/restrained-signal-color.json) | 用强调色区分阅读重点；下划线与可调圆角是本地补充。 |
| 局部反馈 | [按压与聚焦改变容器形状](../entries/patterns/state-shape-feedback.json) | 形状与状态共同反馈；本地浮起、圆角和时长用于比较，未沿用来源 CTA 或资源卡的具体曲线与尺寸。 |
| 方向转场 | [按方向侧向裁切交接整章](../entries/patterns/directional-section-wipe.json) | 遮罩覆盖、内容替换、遮罩退出的方向交接；三章内容与可调时长是本地教学构成，不替代原案例整屏舞台。 |
| 主动声音 | [声音主动启用与随时停止](../entries/patterns/sound-opt-in.json) | 默认静音、用户启用、操作触发、关闭与后台停止；合成短音是本地反馈，未使用来源 BGM、人物语音或操作音轨。 |
| 单开内容 | [单开内容与图像联动](../entries/patterns/single-open-accordion.json) | 当前项展开、其余项收起，正文仍在正常文档流；本地未实现图像联动，也未重现来源的展开曲线。 |

## 来源与证据

取材使用 `entries/patterns/` 中保存的案例字段定位、归档日期与观察原文。证据字段见 [巧思字段说明](../CONTRIBUTING.md#巧思)。

例如，形状反馈保存 Material 的归档观察；方向遮罩保存明日方舟案例的适配记录；单开内容同时包含 Claude 的推断记录以及 Stripe、Qoder 的归档观察。来源参数保存在各巧思中。
