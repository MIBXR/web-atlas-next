# 内容与页面审查清单

收录、字段和呈现标准以[贡献指南](../CONTRIBUTING.md)为准。本清单组织审查流程，按涉及的内容读取对应规则。

## 确认版本与范围

1. 核对远端、当前分支和未提交改动。采用用户指定的版本；未指定时核对远端默认分支，记录基准提交。
2. 列出涉及的条目、页面与共享文件，以只读方式查看目标版本；需要预览时使用独立工作区。
3. 审查默认只读；用户已明确授权修复时，按其范围实施，构建与交付遵循[验收与交付](../CONTRIBUTING.md#验收与交付)。

| 范围 | 覆盖内容 |
| --- | --- |
| 增量审查 | 全部新增或修改内容，以及对应列表、详情、Demo 或原文、来源和关联入口、Agent 资料包与导出。 |
| 全库复查 | 遍历三库条目，覆盖各类内容的展示方式、桌面与手机，以及共享导航、筛选、收藏和详情控件。 |

修改共享布局、字段或模板时，将范围扩大到所有受影响的页面类型。纯条目变更按增量范围审查。

## 逐项操作

1. **核对内容与资料。** 对照条目记录的来源版本，检查名称、摘要、预览、来源与许可、文档和取材文件是否对应；使用[条目字段](../CONTRIBUTING.md#条目字段)判断必填与可选信息。
2. **走完对应入口。** 按下表操作本次范围内的内容，确认入口可访问、显示对象正确、操作及返回结果符合说明。

   | 类型 | 操作路径 |
   | --- | --- |
   | 案例 | 列表进入详情，操作作品，打开独立 Demo、实际出处，以及已有对照和文档，返回列表。 |
   | 巧思 | 对照封面与机制，切换每个来源 Demo，定位并操作，再次定位、重播和返回来源案例；步骤见[来源定位](pattern-experiences.md#详情中的来源定位)。 |
   | 素材 | 按实际类型操作新增或修改的样例、目录、工作流、画廊及对照入口，打开已有原文与文档，确认资料包和导出提供相应入口与依赖。 |

3. **检查呈现与交互。** 在桌面和手机上操作受影响入口，观察首次载入、资源未就绪、切换与返回时的布局和状态；操作实际存在的搜索、选择、滚动、目录、媒体及主题控件。按[站点](../CONTRIBUTING.md#站点)核对结果，保留内容类型和原作行为带来的合理差异。
4. **作出结论。** 逐项记录来自实际页面与文件的证据、已执行的构建检查结果；修复后复核问题触发路径及受影响入口。

## 报告

- **范围与结果**：基准提交、增量或全库范围、实际覆盖内容与结论。
- **问题与建议**：条目、页面或文件位置，触发动作与现象，所依据的规则和修改建议。
- **合理差异**：本轮确认保留的差异及原因。

每轮报告和截图留在工作区或对应 PR。仓库中的本清单保存审查方法。
