# Qoder CN：当前页面的设计与交互

页面以全新 Qoder 双行标题和大幅智能体工作台开场。

## 触发、视觉响应与用途

- 工作台使用公开的固定任务示例，点击本地“新任务”可返回输入界面；本地输入/Enter/发送会进入固定会话，不调用模型。九个阶段按 180/480/760/1000/1200/1400/1600/1900/2250ms 展开；交付文件开关用于显示旁栏。

- 活跃热图在 pointer enter/focus 后 120ms 显示日期/对话提示，在 leave/blur 后 80ms 关闭；很小的元素也能提供可读信息。

- 五平台可通过 tab/点控/触摸切换，以 400ms 水平进退，每 20s 自动切换；悬停/手动暂停，后台停止。快速选择时只保留一个场景。

- 随后是 SDK 代码和 Cloud 任务列表，再到 Wake 场景选择/指针强调、企业、两侧连续证言条带、单开 FAQ 和页尾；所有章节都使用正常滚动。

- 手机端保留工作台的整体缩放裁切和五平台原生横向选项，首屏示例的侧栏结构也保留。菜单、下载说明、Escape/方向键均可操作。

## 完整浏览路径

双行主张 → 公共固定工作台 → 五平台 → SDK/Cloud → Wake → 企业 → 证言条带 → FAQ → 页尾。归档范围仅为该网址在采集日期的页面。

## 主题与声音

当前首页使用固定的灰绿/白色及绿色工作台场景，未发现全局系统或手动主题切换。工作台局部代码的颜色不改变页面主题。

当前公开首页没有 audio/video 或配乐播放器。代码、会话、平台轮播和热图状态提供反馈，工具介绍保持静音。

## 配色、排版与元素协调

主题和运动共同突出产品重点；五平台轮播和集成/Wake/企业章节串联从工具到交付的逻辑。

## 观察依据

公共 NewQoderLiveDemo 模块包含固定 es 对象及九节点时间，本地没有移入实际账户数据；热图延迟也有公开代码依据。已观察五平台原页与真实 390px 缩放布局。源发送状态未验证。
