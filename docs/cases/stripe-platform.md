# Stripe：当前页面的设计与交互

## 触发、视觉响应与用途

- 桌面指针进入或点击分类 → popup 的高度、位移和透明度按源端 300ms 时长过渡，clip/max-height 以 200ms 裁切，均使用 cubic-bezier(.45,.05,.55,.95)；切换分类时连续过渡到各自的自然高度，使目录切换保持空间方向。离开、外部点击或 Escape 关闭，快速反转取消旧动画；减少动态时直接完成。

- 进入页面 → 使用隔离的官方 SingleWave 网格/shader/调色渲染；提供暂停控制，菜单/弹窗/后台/离屏时暂停，GPU 渲染失败时使用官方静帧。

- Payments 进入视口 → 终端文本在 mask 内纵向轮换，checkout 同步更新商户和金额；客户标识连续横移，悬停时可暂停。

- 点击 Bento → 打开产品详情对话框；官网展示产品说明/界面扩展，本地压缩了内容，业务模型反馈明确作为示范呈现。

- 选择 Global 四项统计之一 → 突出当前数字，底部细线进度和基础设施说明对应变化；自动推进，指针停留时暂停。

- 选择 Hertz/URBN/Instacart/Le Monde → 当前故事行展开、其他行收起，真实官方摄影及说明同步替换；来源照片中的平行四边形呼应 Stripe 品牌。

- 页面后半段依次是原生横向架子、四平台选择、深色开发者章节、活动架子、结束行动和页尾；上下滚动保持普通文档，不加入无来源的整屏切幕。

## 完整浏览路径

波浪首屏 → 6 产品 Bento → Global 4 统计 → 4 客户折叠 → Startup 横向架子 → 平台选择 → 海军蓝开发者内容 → 活动架子 → 结束行动 → 页尾。

## 主题与声音

首屏固定浅色及官方波浪；Global/Developers 等章节使用品牌海军蓝，属于章节配色，没有全局主题切换。

当前首页没有背景音乐或有声视频。波浪、产品 UI 和数据选择提供动感，保持金融信息阅读的安静环境。

## 配色、排版与元素协调

配色与动效共同突出产品重点：官方 WebGL 折叠波浪配合连贯段落式主张，产品矩阵、统计和客户故事使用各自的交互机制。

## 源端观察

在源站使用匿名浏览器普通滚动至页尾并返回，实测了产品详情、四项统计及四个客户按钮；SingleWave 渲染模块与三个客户新增摄影均来自官方公开资源。没有全局主题选择和声音控制。

## 移动菜单时序

二级菜单的 transform 500ms、opacity 250ms 使用源 CSS 的 cubic-bezier(.4,0,.2,1)，覆盖层 300ms 使用 cubic-bezier(.45,.05,.55,.95)。
