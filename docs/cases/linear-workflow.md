# Linear：当前页面的设计与交互

工作系统的营销页采用固定暗色，通过首屏面板、Intake 消息转为任务板卡片的过程、AI 代理状态和可编辑代码说明产品价值。

## 触发、视觉响应与用途

- 进入 → 首屏产品 UI 延迟 1.3s 后，用 1.5s 进入，配合背景扫光/mask；下滚时，首屏通过遮罩过渡到后续章节。

- Favorites → 查看独立 issue、看板、统计项目表和项目 overview；其中的任务状态、收藏与 Run agent 是本地工作示例。

- Intake Send “create issues” → 2s 后 Linear 回复，再过 1s，2 张卡插入 Todo；下一次 Send → 1.4s 后回复，800ms 后卡从 Todo 移到 In progress；Replay 恢复初态。整个过程把自然语言请求转成可见的任务变化。

- AI 章节进入视口 → 按 5s 及后续交错时序展示三列代理的思考/回答；离开视口或页面转入后台时停止。暂停按钮与减少动态分支可保持结果。

- Build → 可编辑代码，查看行数反馈，并选择六种 syntax 主题更新局部代码颜色；官网的全局暗色保持不变。

- 手机端缩放并裁切完整应用界面，保留 Intake 消息线程；按原站隐藏 Planning/AI/Build 的复杂图示，保留标题和正文。

## 完整浏览路径

首屏 UI → 客户标识与三个价值点 → Intake → Planning → AI → Build → 结束行动 → 页尾；本地压缩后段数量。手机沿用源站对正文和复杂图示的取舍。

## 主题与声音

营销页固定近黑。Build 中的六种代码主题是局部语法预览控件，不改变全页主题。

当前首页没有配乐、音效和音视频播放器。页面通过消息、任务板和代码的状态变化介绍产品工作流程。

## 配色、排版与元素协调

主题和运动共同突出产品重点：暗色界面贯穿各章节，消息、任务板、AI 代理和代码的状态变化说明产品价值。

## 观察依据

源公共模块提供首屏 1.3s+1.5s、Intake 2000/1000/1400/800ms，以及 AI 思考/交错时间；匿名源 Send “create issues” 实测回复和卡插入。
