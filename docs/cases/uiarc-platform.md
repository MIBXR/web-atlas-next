# Arc UI · 组件平台的产品官网

[案例入口](../../cases.html#style/uiarc-platform) · [独立网页](../../demos/cases/uiarc-platform/index.html) · [对照结果](../../demos/cases/uiarc-platform/fidelity.md)

## 从效果到取用

官网把“能做什么”和“怎样取得”安排在同一阅读流程中。首屏用一句主张解释 React 组件与 AI 工具的关系，两个行动入口分别通往组件目录和 Pro；客户标识随后补充采用背景。先展示六项高级作品，再展示九项日常免费控件，读者能在了解价格前看到两种内容的实际效果。

原站这些卡片使用录制好的静音产品影片。卡片外围的标题、层级标记和一句机制说明方便检索，影片传达运动细节。页面复刻使用相同媒体，卡片展示的是影片，并非可操作组件。可修改的真实免费组件在独立的 [Arc UI 素材](../../materials.html#material/arc-ui) 中。

## 品牌面板与界面主题

首尾都是浅色径向渐变面板：粉色停在左下，蓝色停在右上，黄色从下方延伸，文字占据中间的稳定区域。网页切换为深色主题时，周围表面、灰字、边界和导航一起变暗，首尾面板仍保持浅底深字。品牌识别与工具界面主题分别承担职责。

Geist 的紧字距双行标题是主要视觉锚点，Inter 负责较长的产品解释和操作。主张逐词在裁切框内上升，章节标题在可见面积达到 45% 后从裁切框下方进入。两个网格保持稳定的图文关系：Pro 大卡两列，免费核心三列；手机分别变为一列和两列。

主题切换使用原生 View Transition：旧主题快照保持不动，新主题从水平中线向上下展开，390ms 后覆盖整个画面。固定浅色面板和媒体保留原色，启用减少动态时直接完成切换。

## 安装、方案与疑问

CLI 和 MCP 两张安装卡并列，对同一个产品提供直接操作与 Agent 取用两条路径。命令区只展示一行，复制按钮取得完整命令；相邻卡说明免费与专业内容的数量。

价格区的选中底板以弹簧动效在年度与免费方案之间移动，左栏内容成组退出与进入，终身方案保持可见。FAQ 一次只打开一项，也允许再次收起当前项；原始组件用同一弹簧管理高度接续和图标翻转。手机菜单向下裁切展开，条目错峰进入，关闭时反向收束；Examples 关闭后把焦点交给展示区。

## 取材位置

页面结构在 `index.html`，视觉规则在 `style.css`，主题、标题和媒体由 `app.js` 管理；`source/components.tsx` 组合原始交互组件。产品卡片与客户标识的数据在 `source/content.json`，媒体、字体与发布参照的逐文件事实在素材清单中。构建入口与共享源码用法见本体的制作资料。

与 Google Material 官网相比，本例按免费与专业层级组织组件效果；与 DeepSeek Harness 的任务流程演示相比，本例让每张短片只说明一个组件机制。迁移时先确定产品分组与取用路径，再安排视觉与运动。
