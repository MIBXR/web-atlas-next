# 苏州博物馆：四屏门户、图像目的地与机构外缘

## 一手观察与受控启动

本次源站冷加载被页面末尾同步加载的第三方统计资源阻塞：document 仍为 loading 状态、jQuery 未 ready、四屏高度为 0。停止加载后，调用页面原有的 jQuery.ready()，执行已注册的原始初始化；测量基于受控启动后的原 DOM、CSS 和插件。读取 homeindex.css?d=20190521 及其依赖，以及原有的 fullPage/Owl/lrtk、jQueryUI；实际操作包括点击章节、悬停、查看轮播与页尾。[中文首页](https://www.szmuseum.com/Home/Index)

桌面 min-width 为 1366，左右各留 50px 白缘，四屏同高；原 fullPage 使用 700ms/easeInQuart、4 个锚点和 loopBottom。首页以两张摄影搭配字标和题饰，Owl 每 5000ms 以 fade 切换；展览七项各有真实图片/日期/标题，lrtk 每 5000ms 切换，淡入持续 500ms。第3屏是 75%/25% 不等尺度结构中的九个目的地：资讯、云课堂、馆藏、活动、文创、数字苏博、展览、游戏、建筑美图。图片缩放有 CSS 1.1 倍/500ms 和脚本尺寸 1.1 倍/300ms 两种方式，数字苏博另行增高。第4屏在两张摄影上叠加面积为 70% 的白色半透明访问板。底部完整网站地图的展开时长为 500ms。

官方建筑介绍说明粉墙、深灰石材边饰与自然采光，以及“中而新，苏而新”的理念。[建筑介绍](https://www.szmuseum.com/Other/MuseumIntro) 这些属于实体建筑背景；本页实际白色外缘的尺寸有源 CSS 证据，建筑轮廓保留在摄影内。

## 提取与复用

“多尺度图像目的地目录”抽取九个入口的选择结构；“机构摄影的白色外缘”抽取以 50px 留白包围全幅机构影像的关系。它们是本库对可观察结构的分析。面积权重、图像缩放和章节导航复用既有条目，不另设苏博品牌类别。
