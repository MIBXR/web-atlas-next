# Clawd on Desk：把产品体验放进宣传网页

## 页面任务与结构

页面通过用户与桌宠的相处来宣传产品。开场与终端中的自动表演用于局部说明；观看者通过拖放、权限选择、重播及产品入口决定如何继续，因此整体按互动网页收录。

黑底像素标题建立角色身份，米色点阵花园给用户试探空间。将角色拖入终端后，页面模拟安装过程，再通过权限卡上的 Allow 与 Deny 进入不同分支；允许后以六格动作和真实仓库入口收束。

## 构成与响应式

珊瑚角色是黑底与纸色场景之间的恒定焦点。像素字体负责开场和告别，等宽字体负责终端，画廊用 Fraunces 衬线标题缓和机器感。角色 SVG 的透明留白与可见身体中心分开计算，拖放命中、工作位置及权限卡位置读取同一套几何变量。

`source/website/styles/responsive.css` 使用 `100dvh`、安全区与 `clamp` 约束尺寸。竖向或 ≤600px 的窗口将工作锚点移到终端下角，并给权限操作保留可滚动高度；≤640px 的画廊由三列转两列。

## 交互机制

- **视线与身体**：眼睛按指针方向限幅位移，身体和影子使用更小比例；光标可作为注视目标。眩晕手势只在空闲态生效，拖放和权限动作优先。
- **像素花园**：格点按坐标散列得到固定花形，指针距离决定透明度和尺度；前景交互始终可用。
- **拖放入口**：按下时保存握点，移动时以可见身体判定命中；吸附结束才启动终端，未命中则留在原地。
- **角色与终端**：DOM 对话、思考和权限请求与横行、遮挡、探头和跳跃共同解释产品会如何陪伴编程。
- **权限分支**：允许后进入产品动作；第一次拒绝后，角色作出反应，页面提供一次重试；第二次拒绝后结束请求，用首尾呼应的圆幕和打字机告别。

## 源码与取材

网页入口使用官网直接发布的未压缩源文件，原件及花形生成函数位于 `source/website/`，独立 SVG 的动画关键帧保存在各自文件中。运行文件与字体均在案例包内。产品应用仓库仅用作产品入口和许可依据，官网部署快照与产品 Git 提交分别记录。

与 Linear 的[消息到任务板](../../entries/patterns/message-to-board-demonstration.json)相比，这个案例由用户的拖放和权限选择决定结果；与 DeepSeek Harness 的[过程折叠](../../entries/patterns/process-to-result-collapse.json)相比，这里由同一角色承担动作和状态解释。

已提炼五项独立机制，完整状态、键盘与减少动态限制、同视口对照结果见[fidelity.md](../../demos/cases/clawd-on-desk/fidelity.md)。
