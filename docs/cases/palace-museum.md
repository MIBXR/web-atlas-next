# 故宫：建筑局部与完整文化目录

## 一手观察

本轮逐章读取运行 DOM、main.css?v=763、mScroll 与 xRoll 配置，实际浏览、悬停、打开/关闭菜单、搜索、选择医院第2图、键盘及390px手机回看。建筑区用朱红重复纹理、74.721%宽的屋脊透明摄影、13.276%圆形图饰、中文目录与八个建筑名称组织内容。后续藏品叠层、八典籍条、五历史圆图、两张医院摄影、五文化专题采用不同结构。[源页面](https://www.dpm.org.cn/Explore.html)

医院采用原参数：500ms切换、5000ms循环，悬停时停止；典籍采用1s位移/透明度变化与0.3s序列，反向可恢复；文化专题以原图和半幅浅纸签、竖排器物/书画/文化/人物/展览连接真实目的地。源藏品叠层采用内部滚动。源hoverGif函数在本页没有data-gif目标。

官网的数字文物库、全景故宫、名画记与数字多宝阁分别承担检索、全景、书画细察和三维对象能力。这些能力通过探索页的外链进入，见[数字平台说明](https://www.dpm.org.cn/bottom/platform.html)。

## 提取与复用

“建筑局部锚定文化章节”记录真实对象如何为大色面提供视觉锚点；“图像与半幅纸签分类”记录观看图像与阅读文字如何并置。它们是本库对可观察构成的分析。长页、目录链接与叠层阅读复用库中既有机制，不因机构品牌新增分类。
