## 综合教学框架

本库把网页分成以下三层，可以帮助非专业使用者逐步观察：

1. **视觉材料：你能拿来做设计的东西。** 色彩；字体与排版细节；形状与线条；图像与图标；空间；质感。空间不是“剩下的空白”，而是可主动分配的材料。质感包含光影、颗粒、渐变和表面感，也可以选择完全不用。
2. **组织原则：这些材料如何形成关系。** 布局与对齐；层级与对比；比例与平衡；重复、节奏与一致性。比如同一种按钮始终使用同一形状，相关标题与正文距离较近，不同章节距离更大。
3. **网页体验：这些关系是否服务用户。** 先明确目标和内容顺序；操作后反馈状态；在不同屏幕、键盘与阅读需求下仍然可用。

“协调统一”不要求所有元素都一样。重点内容需要有足够区别，基础规则则应能重复使用。先建立字体、颜色角色、圆角/线条和间距的共同规则，再决定哪里要打破规则来突出重点。

## 案例资料与设计实验室

案例的配色、排版、布局、形状、层级与动效记录在 `entries/cases/<id>.json` 的 `composition`、`tokens` 和行为字段中，`npm run build` 将案例数据汇总为 `data/cases.json`。在 `#/cases/<id>` 阅读拆解、操作完整 Demo，并通过案例比较逐字段查看不同构成。

设计实验室入口：[lab.html](../lab.html)，对应 `#/tools/lab`。同一虚构产品“拾光笔记”保留名称、卖点、功能和行动内容，采用三种原创协调方案：

- **纸页：** 温暖纸白、深墨与陶土强调色；衬线标题；细边框、小圆角；疏朗留白。把重点放在阅读和安静记录。
- **亲和：** 浅绿色、深绿与莓色强调；圆润感无衬线；大圆角、柔和阴影；中等密度。把重点放在轻松上手。
- **工具：** 深蓝、亮文字与青色强调；等宽字体；直边、清晰轮廓；紧凑间距。把重点放在直接、可扫描的信息。

完整方案同时改变配色、字体、形状、留白，并配合图形、质感与反馈。单项实验可以只借用另一方案中的一项，所有产品文案保持不变。页面会说明本次实际改了什么，并提出观察问题：重点是否仍明显、字与形是否表达类似气质、距离是否形成可理解的分组。

实验室还提供实时颜色角色选择、字体选择、三种图文布局、留白范围、圆角选择、三种原创SVG呈现、标题层级对照、平面/颗粒/阴影质感与微动效开关。关闭动效或开启减少动态偏好时，操作反馈按钮仍显示结果文字。两组色彩对比读数对应所选纯色组合。

## 基础Prompt的使用方法

先填写产品、用户和目标，再选择一种主要视觉方向。要求模型给出颜色角色、字体层级、线条/形状与间距规则，解释这些规则如何共同突出核心行动。选择本库真实案例作为具体风格证据，不只写“高级、有设计感”。实现后用手机、键盘、状态反馈和实际内容检验，不以样张好看代替验证。

案例详情提供可复制的实现 Prompt 与负向约束，原文保存在 `prompts/cases/<id>.md`。结合所选案例的具体约束填写目标内容。


## 设计元素怎样统一表达

| 元素 | 在画面中的作用 | 在案例中观察 |
|---|---|---|
| 配色 | 区分背景、表面、正文、强调和反馈 | 阅读色板与配色角色，对照 Demo 中的实际用途 |
| 字体与排版 | 形成语气、阅读节奏和尺度层级 | 对照字体、标题尺度、布局与留白 |
| 图像与图形 | 展示产品、人物、世界或作品 | 查看图像的来源、比例、裁切与质感 |
| 形状与构成 | 把按钮、容器、装饰组织成一致语言 | 观察圆角、几何形状、线条与组合 |
| 深浅主题 | 保持背景、表面、正文与强调的协调 | 阅读主题行为，操作 Demo 自身提供的主题控件 |
| 动效与反馈 | 解释状态变化、引导注意、保持空间连续 | 操作来源 Demo，并阅读关联巧思的触发与参数 |
| 协调关系 | 让所有元素围绕同一主题和重点 | 比较构成说明、约束及可复用 Prompt |
